# Privacy & Security Policy

## Supported versions

The latest release version is actively maintained and supported.

## Reporting a vulnerability

Please report security vulnerabilities by creating a confidential security advisory or opening an issue in our GitHub repository:
https://github.com/dev-abuhurairah/snaptube-refucked/issues

## Privacy
VidSnap respects your privacy. It does not ask for unnecessary permissions, does not include spyware or telemetry, and does not serve ads. Our privacy policy gives detailed information on what data the app stores locally to function, how it is used, and how the app protects your personal information.

## Information Collection and Use

VidSnap respects your personal data. Users have full control over data storage features such as logging downloads or storing website cookies in the app. You can clear data or disable these features at any time in Settings.
- The application does not collect any personal information or analytics.
- VidSnap does not create user profiles or track user behavior.
- VidSnap never shares or transmits your data to third parties.
- VidSnap only requires storage/media permissions to save downloaded files directly to your device storage.

## Open Source Software
VidSnap is free, open-source software built for educational, learning, and research purposes. We welcome and encourage community contributions.

## Changes to Privacy Policy

By using VidSnap, you consent to the handling of your information as outlined in this policy. If you have questions or concerns, feel free to open an issue on the GitHub repository.
